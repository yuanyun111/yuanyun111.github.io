# 缘云 · 个人主页

上海大学经济学院金融学在读。关注数据分析与证券研究。

线上地址：**https://yuanyun111.github.io**

## 技术说明

纯静态站点，**零依赖**：不引用任何外部 CDN、框架或图片素材。页面上的网格、光晕、圆环、噪点、图标全部由 CSS 和行内 SVG 绘制，因此加载快、离线可用、国内访问无延迟。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式、深浅双主题、背景图层 |
| `script.js` | 主题切换、滚动动画、聚光、进度条、背景图探测 |
| `photo.jpg` | **可选** · 头像 |
| `bg.jpg` | **可选** · 全屏背景图 |

## 视觉特性

- **深浅双主题** —— 右上角切换，偏好写入 localStorage
- **颗粒质感** —— SVG feTurbulence 生成的噪点层，深色下 5% 不透明度
- **鼠标聚光** —— 跟随光标的径向高光，仅精确指针设备启用
- **阅读进度条** —— 顶部 2px 渐变条
- **卡片渐变描边** —— 悬停时边缘浮现流光
- **滚动入场** —— 同批元素错开淡入
- **响应式** —— 手机上单列布局，自动关闭聚光与漂浮动效
- **无障碍** —— 尊重系统的「减少动效」偏好

## 加入图片

两张图都是**可选**的，缺省时页面会自动降级，不会破版。

**头像** —— 命名为 `photo.jpg` 放在根目录。方形、接近 1:1 效果最好。文件缺失时自动显示名字首字「缘」。

**背景图** —— 命名为 `bg.jpg` 放在根目录。脚本会探测文件是否存在：

- 存在 → 自动叠加 `blur(3px)` + 降饱和 + 双层蒙版，并压低网格、光晕、卡片透明度，保证正文可读
- 不存在 → 保持纯色渐变背景

无需修改任何代码。建议宽高比 16:9 以上、单边不超过 2560px，并压缩到 300 KB 以内。

## 本地预览

直接双击 `index.html` 即可。若要用本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 自定义

**改主题色** —— 编辑 `styles.css` 顶部的 `--accent` 与 `--accent-2`，深浅两套主题各有一份。

**改内容** —— 直接编辑 `index.html`，每个板块都有注释标注。
