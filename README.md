# 缘云 · 个人主页

上海大学经济学院金融学在读。关注数据分析与证券研究。

## 技术说明

纯静态站点，**零依赖**：不引用任何外部 CDN、框架或图片素材。页面上的网格、光晕、圆环、图标全部由 CSS 和行内 SVG 绘制，因此加载快、离线可用、国内访问无延迟。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式与深浅双主题 |
| `script.js` | 主题切换、滚动动画、导航高亮 |
| `photo.jpg` | 个人照片（需自行放入） |

## 本地预览

直接双击 `index.html` 即可。若要用本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 自定义

**改主题色** —— 编辑 `styles.css` 顶部的 `--accent` 与 `--accent-2` 两个变量，深浅两套主题各有一份。

**改内容** —— 直接编辑 `index.html`，每个板块都有注释标注。

**换照片** —— 把新照片命名为 `photo.jpg` 覆盖即可。方形、长宽比接近 1:1 的效果最好。若文件缺失，页面会自动显示名字首字作为兜底。
