## 技术说明

纯静态站点，**零依赖**：不引用任何外部 CDN、框架或 npm 包。网格、光晕、圆环、噪点、图标全部由 CSS 和行内 SVG 绘制；粒子与视差用原生 Canvas + `requestAnimationFrame`。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式、双主题、背景蒙版与图层 |
| `script.js` | 主题、滚动动画、视差、光尘粒子、进度条 |
| `bg.jpg` | **可选** · 全屏背景图（当前已启用） |
| `photo.jpg` | **可选** · 头像 |

## 动态背景

`bg.jpg` 存在时自动启用，不需要改任何代码。三层效果叠加：

**① 视差位移**
背景比内容滚动得慢（系数 0.045），同时随鼠标产生 ±13px 的横向偏移。位移与缩放分层放在两个元素上，互不干扰；位移有上限，不会露出图片边缘。

**② 呼吸缩放**
52 秒一轮的缓慢放大（1.03 → 1.12），让静止画面有呼吸感。

**③ 光尘粒子**
Canvas 绘制的浮尘，向上飘升并左右摆动。**鼠标靠近 120px 内会被推开** —— 这是主要的交互点。粒子用预渲染的辉光贴图 `drawImage` 绘制，而不是每帧新建径向渐变，帧率稳定。

性能处理：标签页切到后台自动暂停循环；`prefers-reduced-motion` 开启时全部关闭。

## 蒙版机制

明亮的底图会让正文无法阅读，因此叠加了两层蒙版 —— 顶部径向渐变（保护导航栏）+ 纵向线性渐变（保护正文）。各段强度由 CSS 变量控制，深浅两套主题各自独立：

```css
--veil-top: .62;   /* 顶部：导航栏区域 */
--veil-mid: .40;   /* 中部：主内容区 */
--veil-bot: .68;   /* 底部：页脚 */
```

调高 = 图片更淡、文字更清晰；调低 = 图片更透、观感更沉浸。

## 主题

右上角切换深浅，偏好写入 `localStorage`。

**无历史偏好时默认浅色** —— 当前的底图是明亮色调，浅色主题能透出蓝天与草坡；深色主题会叠加更强的暗色蒙版，图片呈电影感的深调，同样可用。

## 本地预览

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

直接双击 `index.html` 也可以，但背景图探测依赖 HTTP，建议用本地服务器。

## 自定义

**改主题色** —— `styles.css` 顶部的 `--accent` 与 `--accent-2`，深浅各一份。

**换背景图** —— 覆盖 `bg.jpg`。建议宽高比 16:9 以上、长边 1920px 左右、压缩到 300 KB 以内。图片明暗变化大时，调 `--veil-*` 三个变量。

**换头像** —— 覆盖 `photo.jpg`，接近 1:1 效果最好。缺省时自动显示名字首字「缘」。

**改内容** —— 直接编辑 `index.html`，每个板块都有注释。
